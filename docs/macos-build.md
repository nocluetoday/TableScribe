# macOS Build

v0.1 targets Apple Silicon macOS first.

## Requirements

- macOS 12 or later
- Node.js and npm
- Rust
- Tauri prerequisites
- Apple Silicon whisper.cpp sidecar binaries

## Commands

```bash
npm install
npm run tauri:dev
npm run tauri:build
```

The macOS app bundle is generated by Tauri. The `.dmg` target is configured in `src-tauri/tauri.conf.json`.

## Microphone Permission

`src-tauri/Info.plist` contains:

```text
TableScribe needs microphone access to record and transcribe RPG sessions locally.
```
