# Model Guide

Models are not bundled in the initial installer.

## Storage

macOS:

```text
~/Library/Application Support/TableScribe/models/
```

Windows:

```text
%APPDATA%\TableScribe\models\
```

## Initial Models

- `base.en`: fast testing
- `small.en`: live draft mode
- `medium.en`: better quality
- `large-v3`: high accuracy final transcript
