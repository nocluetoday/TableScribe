# Microphone Guide

TableScribe records locally and saves raw audio before transcription.

If macOS microphone access is denied, show this message:

```text
Microphone access is disabled. Open System Settings, then Privacy & Security, then Microphone, and enable TableScribe.
```

MVP recording target:

- WAV
- Mono
- 16 kHz or 48 kHz capture
- Preserve original recording if conversion is needed
