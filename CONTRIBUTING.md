# Contributing

Thanks for helping build TableScribe.

## Project Priorities

1. Keep user data local by default.
2. Preserve raw audio before, during, and after transcription.
3. Keep campaign files readable outside the app.
4. Keep macOS and Windows in one codebase.
5. Prefer small, reviewable changes.

## Local Setup

Install Node.js, Rust, and the Tauri prerequisites for your platform, then run:

```bash
npm install
npm run tauri:dev
```

## Pull Requests

Include a short summary, testing notes, and any platform-specific behavior you changed.
